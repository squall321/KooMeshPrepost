Explanation
================================================================================

This exception clarifies that:

1. You can use Qt headers in your proprietary application
   - No need to worry about template or inline code from Qt headers
   - Your code using Qt APIs remains yours

2. You don't need to provide source for header usage
   - Normal LGPL would technically require object files for relinking
   - This exception waives that for standard Qt header usage

3. Your application code is not "infected" by LGPL
   - Using Qt classes doesn't make your code LGPL
   - Only Qt library itself remains LGPL
